# GeoTIFF Viewer

Веб-модуль для подготовки геопривязанных материалов аэрофотосъёмки  
к интерактивному отображению на веб-карте.

## Требования

- Python 3.10+
- GDAL 3.x (системный пакет)
- Зависимости из `requirements.txt`

## Установка

```bash
# 1. Установить системный GDAL (Ubuntu/Debian)
sudo apt install python3-gdal gdal-bin

# 2. Установить Python-зависимости
pip install fastapi uvicorn python-multipart "numpy<2"

# 3. Перейти в директорию проекта
cd geotiff_viewer
```

## Запуск

```bash
python main.py
```

Сервер запустится на `http://localhost:8000`.

## Структура проекта

```
geotiff_viewer/
├── main.py          # точка входа FastAPI: все HTTP-эндпоинты
├── storage.py       # управление файлами и состоянием задач
├── processing.py    # вычислительный модуль (GDAL, gdal2tiles)
├── map_builder.py   # генерация HTML-карты (Leaflet.js)
├── templates/
│   └── index.html   # форма загрузки
├── uploads/         # временные загруженные файлы (авто)
├── tiles/           # сгенерированные тайлы (авто)
└── requirements.txt #(ВАЖНО!!! numpy < 2)
```

## API

| Метод  | Путь                        | Описание                          |
|--------|-----------------------------|-----------------------------------|
| GET    | `/`                         | Форма загрузки файла              |
| POST   | `/upload`                   | Загрузка GeoTIFF и обработка      |
| GET    | `/status/{task_id}`         | Статус задачи                     |
| GET    | `/result/{task_id}`         | HTML-карта                        |
| GET    | `/tiles/{task_id}/{z}/{x}/{y}.png` | Тайл по координатам       |
| GET    | `/download/{task_id}`       | ZIP-архив тайлов                  |
| DELETE | `/task/{task_id}`           | Удаление задачи и файлов          |

## Ограничения прототипа

- Максимальный размер входного файла: 500 МБ
- Поддерживаемые форматы: GeoTIFF (.tif, .tiff) с геопривязкой
- Поддерживаемые каналы: 1 (grayscale), 3 (RGB), 4 (RGBA)
- Обработка синхронная; одновременная обработка нескольких файлов
  ограничена пропускной способностью сервера
- Файлы задачи удаляются при следующем запуске сервера, если им > 24 ч
